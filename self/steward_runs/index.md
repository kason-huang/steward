## 新增记录

1. 以任务开始时间建目录，格式为 `YYYY-MM-DD_HHMMSS_<scenario>_<body>_<phase>`。同一场景多次运行分别记录，并注明时区。
2. 在重置或换场景前保存目标判分、关键对象位姿、末次技能附近的 Observer 采样、任务最终回复和工具调用统计。大日志留在运行目录，基线只归档支撑结论的字段。
3. 用下面的模板写 `report.md`，然后在索引新增一行。缺失字段记为未记录或未核实。离线回放与在线任务分别记录耗时和结果。

## 记录模板

| 区块 | 记录内容 |
| --- | --- |
| 运行配置 | Scenario、本体、感知级别、版本、种子、模型、感知服务与缓存状态、时钟模式、会话 ID |
| 任务结果 | 开始和结束时刻、墙钟与仿真耗时、终止原因、机器人自报、独立判分 |
| 阶段记录 | 完成和失败的步骤、重试与人工介入、关键技能及工具次数 |
| 感知表现 | 阶段性召回与误检、位置误差、ID 切换、关键帧和分割耗时。注明采样时刻与观测条件 |
| 对照与附件 | 对照运行、固定的实验条件、本轮改动、可复核的快照和日志 |
