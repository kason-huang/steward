# Step 6：在 Panda ER 接入 π0.5 闭环

2026-11-11。初态 0 的真实推理、观测门禁、完整抓放、撤爪后的篮底承托与动作复放已实测通过。冻结推理时钟下的最小闭环通过，实时模式和正式技能风险覆盖继续验收。对应[实施计划第 6 步](../pi05-integration-plan.md#6-接入-π05-闭环执行)。

结果、输入和动作回执见[初态 0 实测报告](step6-results/README.md)。完整回合共 31 次推理、155 条应用动作，五动作一重规划，双机位录像和全部失败尝试见[完整抓放报告](step6-results/full-task/README.md)。

## 1. 首轮范围与准入

首轮使用 4090-2 的 Panda WSim、初态 0 和已在 Step 1 验证的字母汤罐任务、OpenPI 版本与 `pi05_libero` 权重。Step 4 的固定动作和物理记录提供故障定位与对照。正式接入前先复核策略进程的版本、权重及配置、输入分辨率、输出维度和服务连通性。运行使用独立验证目录和端口。[Step 4 正式批次](step4-results/formal-batch/README.md)

Step 5 的准入项是同一仿真步的两路 RGB、8 项本体状态、稳定的 Episode 和步号，以及缺帧、过期和重置时禁止提交新动作的检查。用固定版 LIBERO 核对输入方向、字段顺序、单位和参考系。Ego State 的抓放判断作为辅助证据。碰撞后倾斜罐体等未确认样例可以保留，物理结果由独立 WSim 验收侧判定。完整抓放识别和负例验收在启用 Ego State 自动判定任务完成前交付。[Step 5 阶段结果](step5-results/README.md)

## 2. 闭环执行

1. Panda ER 接收固定任务请求，绑定 Episode、本体、策略配置、任务目标、操作区和预算。首轮提供独立验证入口，复用第 3 步的执行器租约。任务级预测、启动、状态和停止保留可对接接口，EH 工具链的端到端验收在 Step 7。
2. 从机器人传感器端口读取同步观测，用 Step 5 的编码生成两路 224×224 RGB、8 项本体状态和任务指令。通过固定版 OpenPI WebSocket 客户端发起推理。ER 为每次请求记录观测步、控制代次、请求编号和截止时间。策略服务只接收推理输入。
3. 验证输出为非空的有限数值动作序列，每项七维，按固定版动作约定解释。检查前缀的动作范围、累计位移、关节和夹爪限位、工作区及授权条件。检查可观测障碍与预期接触范围。证据不足时拒绝候选前缀。正式技能验收要求覆盖相应预测能力，具体风险覆盖与缺口写入报告。[接入设计](../pi05-integration-design.md#7-动态动作如何经过安全检查)
4. 每次只提交通过检查的有限前缀。建议先用短前缀验收调度和停止，再按原始运行配置与实测延迟选择正式前缀长度，记录配置和理由。使用固定控制周期，等待 WSim 实际应用回执，丢弃本批剩余动作并重新取样。推理服务的响应速度不决定控制周期。
5. 显式停止、租约过期、预算用尽、推理超时、观测失效或 Episode 切换时，撤销控制代次、清空未应用动作并记录最后一个已应用动作。迟到响应在提交前复核 Episode、控制代次及请求状态。按 Step 3 的速度窗口分别报告撤销成功和物理停稳。[Step 3 实测](step3-results/README.md)

首轮可采用确定性仿真时钟，使推理期间的世界状态与输入对齐，同时记录墙钟延迟。报告单列冻结推理和实时模式。固定观测年龄上限、请求超时、动作数和墙钟预算后再运行。

## 3. 验证顺序与产物

| 验证 | 通过证据 |
| --- | --- |
| 只推理 | 同一帧的输入可与 Step 5 预览对照。真实权重返回符合协议的动作序列，执行器未获得动作。 |
| 有限前缀 | 初态 0 至少完成多轮真实的取样、推理、检查、执行和重新取样。记录候选动作、拒绝原因、接受与应用回执、前缀边界及对应仿真步。 |
| 故障与停止 | 注入超时、NaN、维度错误、越界动作、缺帧、过期观测、重置和执行中停止。验证故障之后无旧动作应用，保留停止状态和独立轨迹。 |
| 原任务实测 | 运行字母汤罐任务，分别报告夹持、搬运、释放和物理放置结果。正常完成以撤爪后篮底承托及稳定窗口为证据。保留失败阶段、未确认和人工干预。 |
| 动作复放 | 在同一初态复放实际应用的动作和步号，对照轨迹及物理结果，记录任何时序或接触差异。 |

结果保存至 `steps/step6-results/`，包括模型和配置标识、复现命令、观测引用、推理及动作日志、故障处置和双机位录像。大体积输入、输出和逐步轨迹保留在 4090-2 的独立运行目录，报告记录路径及校验值。正式成功率与 EH 工具验收继续按后续步骤实施。
