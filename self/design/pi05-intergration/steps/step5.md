## 1. WSim 观测与 Ego Runtime

1. 在 Panda 的机器人端口新增同步观测入口，先定义数据包和权限。使用 Step 3 的固定相机 `overview`（源模型的 `agentview`）和 `robot0_eye_in_hand`。两路图像及关节反馈从同一冻结的 MuJoCo 状态采样，记录 `episodeId`、物理步、仿真时间、相机标识和标定版本。通过同一份快照渲染，避免等待 EGL 时推进到另一帧。现有控制台自由视角继续用于人工查看，Panda 的外部观测绑定固定相机。
2. 同一观测包提供按名称映射的七个臂关节与两指位置、速度，包含单位、符号和参考系。用固定基座、关节树和传感器标定在 ER 侧求腕相机与末端位姿，复用估计器的前向运动学。以原版 `robot0_eef_pos`、`robot0_eef_quat` 对照工具站点、参考系与旋转约定，校验双指顺序与符号。标定产物包括两路内参、固定相机外参、腕相机相对末端的刚性变换以及用于投影检查的样例。
3. 以 Panda 观测适配接入 `RobotLink`、`EgoEstimator` 和现有 Ego State 发布链路。按 Scenario 启停 Panda ER，发布机器人自身、物体轨迹、关系和最新观测时间，控制台可查看 Ego State 和两路观测。现有 ER 构造器会默认创建厨房平面臂及技能执行器，Panda 采用专用的观测配置，固定动作仍由 Step 4 客户端通过原控制端口提交。Episode 重置或切换时清空轨迹、判断和观测缓存，迟到帧按 Episode 和步号拒绝。
4. 机器人侧的罐与篮身份来自视觉识别及跨帧关联，保存 Ego State 局部引用。用双视角匹配、相机几何和短时跟踪建立目标位置及篮口关系。先评估 RGB 的可见性和深度歧义；若单凭 RGB 与编码器不足以区分篮沿、篮底或前后遮挡，先量测缺口，再决定是否为 Ego State 增加经过标定的深度观测。策略输入仍沿用固定版 OpenPI 的两路 RGB 和本体状态。
5. 机器人侧仅访问传感器及本体反馈。世界侧物体 ID、真值位姿、接触记录、BDDL 谓词和回合结果留在独立验收进程。实现后检查数据包字段、ER 配置和策略输入，并验证 ER 在世界诊断服务关闭时仍可运行。观测时钟请求沿用非推进式等待，控制客户端继续负责仿真推进。

## 2. 固定版 OpenPI 输入

| 字段 | 计划和对照 |
| --- | --- |
| `observation/image` | 固定外部视角，RGB `uint8`，按 LIBERO 示例等比例缩放并补边到 224×224。 |
| `observation/wrist_image` | 固定腕部相机，使用同样的数据类型和尺寸，按观测包物理步与外部视角配对。 |
| `observation/state` | 8 项，依次为末端位置 xyz、末端旋转轴角三分量、两个手指关节位置。七个臂关节位置和速度用于本体反馈及 FK，按固定版 OpenPI 示例另生成 8 项输入。 |
| `prompt` | 任务说明，从请求或任务配置传入。 |

原始 LIBERO 示例会把两个原始相机数组的行和列同时反转后再缩放补边。WSim 渲染方向须用同一初态下的非对称场景和重放中的运动方向逐路对照，按最终输入对齐，并记录实际变换。结合原版 `_quat2axisangle` 检查单位、四元数顺序、符号和近零旋转。验收保存两路原始 RGB、实际待送策略的两路 RGB 及 8 项状态，记录同一帧的仿真步。Step 6 再使用该输入调用 π0.5。

## 3. Ego State 的抓取和放置判断

分别记录抓取与放置的判断、关联的目标引用、支持帧和原因。状态包括 `confirmed`、`failed` 和 `unconfirmed`，执行中的暂时观测单独保留。冻结连续帧数、最大观测年龄、最小可见性及稳定窗口。正式评分前，单独用调试样例选定阈值。

| 判断 | 可用证据 |
| --- | --- |
| 抓取确认 | 观察到同一个罐靠近指间，合爪后罐体随末端抬升，并在多个新鲜观测中保持相对位置。用双指实际位置、开口变化和末端运动交叉核对。 |
| 抓取失败 | 抬爪后仍能辨认原罐留在原地，或观察到罐脱离夹爪并下落。连续观测不足时记为 `unconfirmed`。 |
| 放置确认 | 观察到同一罐在松爪、撤爪之后留在篮口投影内，并有足够证据区分篮内与篮沿、前后遮挡。篮与罐的相对位置在稳定窗口内持续成立。 |
| 放置失败 | 撤爪后能定位汤罐在篮外、挂在篮沿或从篮中掉出。遮挡、引用混淆和过期观测记为 `unconfirmed`。 |

## 4. 验收与交付

- **同步和标定。** 在固定姿态和腕部运动期间，对照原始 LIBERO 的帧方向、关节映射、末端位姿和投影。验证两路图像和编码器来自同一物理步。注入重复帧、迟到帧、缺失相机、跨 Episode 数据及遮挡，检查状态退化与重置行为。
- **逐回合重放。** 复用 Step 4 的五个初态、两次复位和五类负例动作表，保留外部视角与腕部相机。对每个环境使用该回合自身的物理标签，逐项比较 Ego State 的抓取及放置结论。携物碰撞单列。WSim 若观察到罐稳定落入篮底，允许确认放置；原始 LIBERO 的篮沿样例按失败或证据不足评分。原始录像与原始观测用于对照，WSim 回合通过真实 ER 观测入口验收。
- **验收口径。** 逐回合报告正确确认、正确失败、错误确认、错误失败和未确认，并分别给出抓取、放置的覆盖率和时延。在有足够可见性的预留验收样例中，每类正常与失败结果均需有正确的明确结论。正式批次不得把实际失败报为已确认成功，明确遮挡样例应返回未确认。公开未确认的数量和原因；若正常样例中的放置长期不可见，先解决观测缺口再进入 Step 6。
- **产物。** 将字段规范、标定、逐回合判断与独立世界侧对照、预处理样例、同步与信息隔离检查、控制台截图、复现命令和报告保存至 `steps/step5-results/`，记录 4090-2 上的原始帧和轨迹路径。
