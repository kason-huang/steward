## 2. 实施顺序

1. **先在原始 LIBERO 调通初态 0。** 使用与 Step 3 相同的源码、资产、控制器和初态快照。按「预张开 → 从上方接近 → 下降到可夹高度 → 闭合 → 提起并悬停 → 越过篮沿搬运 → 下降到释放高度 → 张开 → 撤爪 → 静置」逐段录制。把段名、每周期动作、周期数和起止物理步保存为可重放协议。夹爪正值闭合、负值打开、零值保持累计目标，闭合时长按实际指距和接触响应确定。
2. **接通 WSim 重放和世界侧采样。** 从对应的预热结束快照复位，在真实机器人端口逐周期提交，按应用回执推进，核对命令没有漏执行、重放或跨 Episode 泄漏。给两个环境的证据统一相对仿真时钟和命名映射。由专用验证器采样接触、物体轨迹和成功判定。
3. **先比较初态 0，再扩到初态 1–4。** 优先尝试共用动作序列。若固定初态之间的物体位姿差要求使用不同接近或放置段，可按初态预先生成并冻结动作表，同一初态在两边使用相同动作。调试期间单独记账。正式跑批前冻结资产与配置哈希、动作表、判定阈值和超时预算；运行时不根据物体真值改动作。
4. **按阶段定位差异。** 无接触阶段先检查复位、动作和相机记录。接触阶段比较接触几何、法向力、双指宽度和汤罐相对夹爪的滑移，再比较求解器、摩擦、接触过滤、质量与惯量。若需修改模型或控制参数，记录源配置与改动原因，重跑受影响的 Step 2 承托与 Step 3 控制回归。

## 3. 试验矩阵与验收

| 用例 | 方法 | 通过证据 |
| --- | --- | --- |
| 正常夹持、抬升与搬运 | 夹住直立汤罐，提起、短暂悬停，再移动至篮上方。 | 合爪阶段两个指垫均对汤罐产生正向接触力。汤罐离开初始支撑面，在悬停窗口持续受夹爪接触维持，且相对夹爪的位移和姿态变化在冻结的滑移容差内。搬运过程中没有落物。 |
| 自然释放与篮底承托 | 在篮口内释放，抬爪撤离，并静置观察。 | 双指与汤罐接触解除，汤罐随后由篮底碰撞几何承托。撤爪后在冻结的观察窗口内，原版 LIBERO 目标谓词持续为真，线速度和角速度低于阈值，且有正向篮底承托、没有地面或指垫承托。 |
| 抓空 | 在没有目标物体的区域闭合并抬升。 | 无目标接触与随动，任务判定保持失败。 |
| 偏位或夹持不足 | 分别使用冻结的横向偏移与缩短闭合段，随后执行提起。 | 记录单侧接触、未提起或滑落。若原始环境的试验仍抓稳，调整调试用例并在正式跑批前固定参数；正式批次保留所有实际结果。 |
| 携物碰撞 | 使用单独的受控路径，在保持夹持时让汤罐与篮沿接触，留出明确的无碰撞对照。 | 记录真实接触对、法向力及受阻、偏转或滑落等实际响应，检查有无穿透、穿越或隐式附着。 |
| 篮外释放 | 在篮口外放下并撤爪。 | 记录地面或预定的篮外支撑，原版包含谓词及物理放置判定均为假。 |

每个环境的正常验收批次预定覆盖初态 0–4，每个初态独立复位重放两次。目标是五个初态各两次均满足抓取与放置判定。负例独立成批，在两边使用相同的初态和动作。正式运行前根据原始 LIBERO 调试测量冻结抬升高度、悬停和静置窗口、相对滑移容差、线速度与角速度阈值及最小接触力。Step 2 最后 0.25 s 的观察窗口可作为静置初始设定。负例的通过表示物理响应符合预期，和正常任务成功率分开报告。失败、超时和人工干预保留原记录。

报告逐回合分别给出 **LIBERO BDDL 目标是否达成**与 **WSim 物理放置是否达成**。世界侧复用 Step 2 对原版谓词的对照实现，并用真实接触和静置指标补充承托证据。篮口边缘或仅碰到篮壁时，即使包含谓词短暂为真，也不计为稳定放置。两项判断不一致时，保留进入篮口、释放、首次承托和静置结束的关键帧及数值。
