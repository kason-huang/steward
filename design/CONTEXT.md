# Steward 派生项目 · 术语

## 世界与机器人

**World Harness（WH）** 是实验员使用的智能体，负责构建场景、安排任务和施加扰动。**World Control API（WCA）** 是它操作世界的接口。

**Episode（回合）** 是在指定场景、初始状态和构型中运行的一次实验。**World State（WS）** 是该回合物理世界的真实状态，由当前仿真实例持有。

**Observer** 是世界侧评估者。它接收机器人状态估计的副本，与世界真值比较，产出仅供实验评估的结果。

**Ego Harness（EH）** 是机器人的模型会话、上下文、工具和反思机制的组合。在本设计中承担高层 S2 的角色。

**Ego Runtime（ER）** 是机器人侧持续运行的感知、估计、预测和技能执行环境。Ego Harness 通过 Ego API 使用它。

**观测** 是某传感器在指定坐标系和时刻取得的读数或图像。**Ego-State（ES）** 是机器人对现场与自身的估计，可包含不同采集时刻的字段。**物体轨迹** 是对同一物体跨帧维护的机器人侧身份、位置、不确定度和可见性。

## 预测、执行和验证

**ESim** 是基于 Ego-State 预测候选动作后果的能力。**预测回执（Prediction Receipt）** 包含技能、参数、计划、可行性、风险和有效期。

**技能（Skill）** 是机器人可调用的能力。**作业（Job）** 是一次具体执行，有执行状态、起止时刻和日志，有些技能还给出后置条件。**任务（Task）** 是用户关心的目标，可以涉及多个作业，也可以通过只读观测完成。

**S1 技能执行** 根据计划和观测生成关节与夹爪目标，跟踪作业进度。**S0 本体控制** 检查运动授权，驱动执行器，提供本体反馈并确认停稳。S0 的仿真实现位于 StewardHost 的机器人端口和 MuJoCo 控制循环。

**反思** 是高层依据失败或进展事实重新审视目标、假设和下一步。**任务验收** 是机器人依据新观测判断是否满足用户意图，证据不足时可以报告未知。**独立评分** 使用实验侧真值衡量结果。

## PiPER 扩展术语

**意图版本** 标识当前用户目标和验收条件。**计划版本** 标识为某一意图选定的步骤。用户改口会更新意图；同一目标下失败重试可以只修订计划。

**执行代次** 是一个控制资源当前接受的运动授权版本，用于隔离作废队列和迟到动作。**停稳确认** 是执行端依据本体反馈给出的停止证据。

**执行回执** 是适配器报告的受理、终止或停止确认等事实，与动作前的预测回执分别记录。**复查事件** 是需要高层重新判断的变化，应带来源、时刻和关联证据。
